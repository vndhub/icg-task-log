# ICG Task Log — GitHub Pages Setup

## What you'll get
A live URL like `https://yourname.github.io/icg-task-log/` that works on any device (desktop, iPhone, iPad). Data auto-saves on each person's device.

## Setup (5 minutes, one-time)

### Step 1 — Create a GitHub account
1. Go to **github.com** and click **Sign up**
2. Use any email. Free account is all you need.

### Step 2 — Create a new repository
1. Click the **+** button (top right) → **New repository**
2. Repository name: **icg-task-log**
3. Set it to **Public**
4. Check **Add a README file**
5. Click **Create repository**

### Step 3 — Upload the file
1. In your new repo, click **Add file** → **Upload files**
2. Drag and drop the **index.html** file from this folder
3. Click **Commit changes**

### Step 4 — Turn on GitHub Pages
1. Go to **Settings** (tab at the top of the repo)
2. In the left sidebar, click **Pages**
3. Under "Source", select **Deploy from a branch**
4. Branch: **main**, folder: **/ (root)**
5. Click **Save**
6. Wait 1-2 minutes, then refresh. You'll see:
   **Your site is live at https://yourname.github.io/icg-task-log/**

### Step 5 — Share with team
Send that URL to Phi and Uyen. They open it in any browser — done.

## That's it!
No server, no database, no monthly cost. The page is static and each person's data stays on their own device via localStorage.
